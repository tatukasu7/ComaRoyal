# 駒ロワ

将棋の駒1つ＝プレイヤー1人。全員が同時に1手ずつ動く、最大8人のバトルロイヤル。

- 全員「歩」から始まり、盤上の駒を拾って動きを覚え、相手を取って動きを奪う
- 盤は数手ごとに外側から落ちていき、最後の一駒が勝ち
- 同時ターン制なので、相手が動くか留まるかを読み合う

## 遊び方

| モード | 内容 |
|---|---|
| ひとりで | CPU 7体と対局。CPUの強さは やさしい / ふつう / つよい |
| オンライン | 部屋を作って招待リンクを送るだけ。ログイン不要。足りない席はCPUが埋める |

対局はブラウザに最大30局まで記録され、「振り返る」で1手ずつ再生できる。

## ルール(試験ルールはすべてオン/オフ可能)

- **同時進入**: 2つの駒が同じマスに同時に入ったら強い方が勝つ。比べる順は 素の歩 → 動きの数 → 動きの価値 → 撃破数。完全に互角なら両方弾かれる
- **留まった駒は取られる**: 待機・向き変えの駒のマスに入ってきた駒は、強さに関係なく取れる
- **歩は轢けない**: 何も覚えていない歩は、動いた先で同時にかぶれば必ず勝つ
- **読みで突破**: 飛・角・香は駒の先まで狙える。通り道の駒がその場に残っていたら手前で止まる
- **決戦場**: 盤は3×3で止まり、24手目から1マスずつ落ちる
- **将棋の成り**: 成ると 歩→と、香→杏、桂→圭、銀→全、角→馬、飛→龍。成るかどうか・いつ成るかは選べる
- **玉座**: 決戦場では、成れる場所が中央の1マスだけになる

## ローカルで動かす

```bash
npm install
npm start          # http://localhost:8080
npm test           # エンジンとサーバーのテスト
```

`public/index.html` を直接ブラウザで開いても、ひとり用は遊べる(オンラインはサーバー経由のみ)。

## 公開する(Render の例)

1. https://render.com にGitHubでサインインする
2. 「New +」→「Blueprint」でこのリポジトリを選ぶ(`render.yaml` が読み込まれる)
3. 発行されたURL(`https://koma-royale-xxxx.onrender.com` など)を友達に送る

無料プランは15分ほど誰もアクセスしないと眠り、次のアクセスで起きるまで数十秒かかる。対局中の部屋はサーバーのメモリにあるので、サーバーが再起動すると消える。

Docker が使える環境なら `docker build -t koma-royale . && docker run -p 8080:8080 koma-royale` でも動く。

## 構成

```
public/engine.js     ゲームのルール・CPU・同時解決(ブラウザとサーバーで共通)
public/index.html    画面(ひとり用・リプレイ・オンライン)
server/server.js     静的配信 + WebSocket(/ws)。部屋と対局の進行はすべてサーバー側
server/engine-loader.js  engine.js を Node に読み込む
test/                エンジンとサーバーのテスト
```

オンラインでは、各プレイヤーの手はサーバーにだけ送られ、全員がそろうか制限時間(45秒)が来るまで他の参加者には見えない。切断した席はCPUが代わりに指し、同じブラウザのタブで開き直すと席に戻れる。

### 環境変数

| 名前 | 既定値 | 内容 |
|---|---|---|
| `PORT` | 8080 | 待ち受けポート |
| `TURN_MS` | 45000 | 1手の制限時間(ミリ秒) |
| `AUTO_MS` | 700 | 人間が全員脱落した後の自動進行の間隔 |
